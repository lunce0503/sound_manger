# Sound Manager v1.0.0

Windows 서버의 음원 수신·믹싱·출력을 Rust로 전환했습니다. Windows는 단일 EXE,
Android는 기존 서명 키를 유지한 APK로 배포합니다.

- Rust DSP, 인증 REST/WebSocket 서버, WASAPI 출력. WPF 화면과 Android Java 앱, Chrome·Edge 확장 및 v1 PCM 프로토콜을 유지합니다.
- 기기별 자동 음량 보정, 5 ms look-ahead 출력 리미터, 실효성 있는 소규모 클록 보정. 자동 보정은 기기 메뉴의 음량 조절에서 켜며 서버에서 기준 레벨·최대 증폭을 설정합니다.
- Windows EQ는 별도 창에서 설정합니다. 음소거 저장 중·완료 후 오래된 상태 조회가 토글을 되돌리는 문제를 수정했습니다.
- Rust 서버 종료를 감지하고 저장된 출력 장치로 재시작하며 기존 외부 터널 주소·인증을 유지합니다. 인증·기기 설정·트레이 백그라운드·로그인 자동 실행과 서명된 업데이트를 유지합니다.
- Windows 실행 파일·창·트레이에 새 아이콘을 적용하고 바탕화면·시작 메뉴 바로가기를 준비합니다.

기존 0.4.1은 앱의 업데이트 기능을 이용할 수 있습니다. 이전 버전은 아래 EXE·APK를
직접 실행·설치하세요. Android 앱을 삭제하지 않고 업데이트하면 페어링이 유지됩니다.

자동 음량 보정의 dBFS는 디지털 신호 기준입니다. 이어폰·스피커의 실제 음압을 측정하거나
60 dB SPL로 제한하는 기능은 아닙니다. 실제 Android 기기 캡처·청취 검증은 추후 진행합니다.
10소스 30분 연속 자동 검증에서 버퍼 부족·폐기·trim 0회를 확인했습니다. 검증 범위와 재현 명령은 저장소의 `docs/validation-v1.0.0.md`와 `docs/rust-migration.md`에 기록합니다.

Windows: `SoundManager-1.0.0-windows-x64.exe` · Android: `SoundManager-1.0.0-android.apk`
무결성·자동 업데이트용 `SHA256SUMS.txt`, `update.json`, `update.json.sig`를 함께 제공합니다.
