# Sound Manager v0.3.3

음원 제공 기기가 연결을 끊었다 다시 연결해도 기기별 음량과 음원 위치를 유지합니다.

- 음량·음소거·방향 각도·공간 효과 사용 여부를 서버에 저장합니다. 네트워크 단절, 캡처 재시작, 서버 앱 재시작 후에도 복원합니다.
- 모델명이나 PC 이름 대신 앱에 저장한 무작위 ID로 기기를 구분합니다. 같은 이름의 기기도 독립적으로 설정하며, 이름을 바꿔도 유지합니다.
- 첫 PCM을 처리하기 전에 복원하며, 이전 연결이 정리되지 않은 재연결도 처리합니다. 끊긴 기기는 활성 목록에서 사라지지만 설정은 보관합니다.
- 저장 실패 시 이전 설정을 유지하고 오류로 응답합니다. 손상된 설정 파일을 기본값으로 덮어쓰지 않습니다.
- Windows 서버와 음원을 보내는 Windows/Android 앱을 모두 업데이트하세요. 이전 전송 앱도 연결되지만 기기별 자동 복원을 지원하지 않습니다. 앱 데이터나 기기 ID를 지우면 새 기기로 처리합니다. 기존 버전에서 저장하지 않았던 설정은 업데이트 후 다시 지정해야 합니다.

Windows는 `SoundManager-0.3.3-windows-x64.exe` 단일 파일로 배포합니다. 기존 앱을 완전 종료한 뒤 새 EXE를 실행하세요. Android는 `SoundManager-0.3.3-android.apk`로 업데이트하며 기존 서명과 페어링 정보를 유지합니다.

전체 음량의 초기값·EQ와 기존 로그인 자동 시작/백그라운드 동작은 유지합니다.

실제 HTTP/WebSocket 연결에서 설정 변경, 정상/강제 연결 종료, 재연결, 같은 이름의 다른 기기, 서버 재시작, 연결 교체, 동시 변경, 저장 실패를 검사합니다. Windows/Android 기기 ID의 저장·재사용도 자동 테스트로 검증합니다. 실제 Android/Bluetooth 다중 기기 청취 검증은 별도입니다.
