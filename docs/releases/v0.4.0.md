# Sound Manager v0.4.0

Chrome·Edge 탭을 각각 음원으로 전송하고 서버에서 조절할 수 있습니다. Windows·Android 목록을 이름과 음소거 중심으로 정리했습니다.

- 목록에는 기기/탭 이름, 스피커 아이콘과 음소거 토글, 세로 점 세 개(⋮) 메뉴만 표시합니다.
- Windows 서버와 Android의 **⋮ → 음량 조절 / 이름 변경 / 360° 방향 설정**에서 조절합니다. 음량은 0–200%, 이름은 1–64자이며 원래 이름으로 복원할 수 있습니다.
- 서버에서도 기기·탭별 음량과 음소거를 직접 바꿉니다. 변경한 항목만 저장해 다른 화면의 설정을 덮어쓰지 않습니다. 이름·음량·방향·음소거는 재연결·서버 재시작 후에도 복원합니다.

## 탭 전송 시작

1. 기존 앱을 완전 종료한 뒤 `SoundManager-0.4.0-windows-x64.exe`를 실행합니다.
2. **브라우저 탭 연결 → 브라우저 확장 설치 폴더 열기**를 누릅니다.
3. Chrome/Edge의 확장 관리에서 개발자 모드를 켜고 열린 폴더를 압축해제된 확장으로 로드합니다.
4. 보낼 웹 탭에서 확장을 열고 **서버 연결 관리**에 서버의 복사한 연결 코드를 등록합니다. 서버 호스트 접근 권한을 허용합니다.
5. 탭마다 **이 탭 전송 시작**을 누릅니다. 이후 서버 또는 휴대폰 목록에서 따로 조절합니다. 팝업을 닫아도 전송합니다.

브라우저를 다시 열었을 때는 저장된 탭 설정을 선택하고 전송을 시작하면 이전 값을 복원합니다. 캡처는 사용자가 시작해야 하며 DRM·캡처 금지 음원·브라우저 내부 페이지는 지원하지 않을 수 있습니다. 데스크톱 Chrome·Edge 116 이상을 대상으로 하며 모바일 브라우저 캡처는 지원 범위에 포함하지 않습니다.

탭의 로컬 소리는 서버 출력으로 전달됩니다. 탭 전송과 같은 PC의 전체 재생음 전송을 동시에 켜면 중복 전송·출력 재입력이 생길 수 있으므로 전체 PC 전송은 중지하세요.

Windows는 확장 파일을 포함한 단일 EXE, Android는 기존 릴리스 서명을 유지한 `SoundManager-0.4.0-android.apk`로 제공합니다. 서버와 Android를 함께 업데이트하세요. 기존 v0.3.3 기기 설정·페어링·자동 시작 설정을 유지합니다. 확장 스토어 게시는 포함하지 않습니다.

실제 격리된 Chromium에서 두 탭 캡처, PCM 수신·믹싱, 팝업 종료 후 전송, 서버 음량·음소거·이름 변경, 브라우저 재시작 후 인증·탭 설정 복원을 검증합니다. Windows/Android 메뉴·조절 창과 백엔드 저장 테스트도 포함합니다. 실제 Android/Bluetooth 청취 검증은 별도입니다.
