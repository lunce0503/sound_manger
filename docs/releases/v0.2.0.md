# Sound Manager v0.2.0

서버 QR 연결과 외부 네트워크 연결을 추가한 시험 릴리스입니다.

## 다운로드와 설치

- `SoundManager-0.2.0-windows-x64.zip`: 압축을 모두 풀고 `SoundManager.Windows.exe`를 실행합니다. .NET 런타임이 포함되어 있으며 `cloudflared.exe`를 같은 폴더에 둡니다.
- `SoundManager-0.2.0-android.apk`: Android 10 이상에 설치하는 릴리스 서명 APK입니다. 이전 0.1.0 개발용 APK와 서명이 다르므로 기존 개발용 앱이 설치되어 있다면 먼저 제거하고 설치해야 합니다.
- `SHA256SUMS.txt`: 배포 파일 SHA256.

이 배포는 GitHub에서 직접 설치하는 방식입니다. Google Play/Microsoft Store 등록이나 Windows 게시자 코드 서명은 포함하지 않습니다.

## 연결

1. Windows 앱에서 출력 장치 선택 → **서버 시작**.
2. 같은 Wi-Fi에서는 해당 LAN 주소의 QR을, 다른 Wi-Fi/모바일 데이터에서는 **외부 네트워크 연결 켜기** 후 생성된 QR을 사용합니다.
3. Android의 **QR로 서버 연결** → 스캔 → 서버 주소 확인 → **연결**.
4. 휴대폰의 **재생음 전송 시작** 또는 다른 Windows PC의 **음원 전송 시작**으로 소리를 보냅니다.

카메라 사용이 어려우면 Windows의 **연결 코드 복사**를 휴대폰에 전달하고 Android의 **복사한 연결 코드 붙여넣기**를 사용할 수 있습니다. Windows 클라이언트도 같은 코드를 적용할 수 있습니다.

## 변경 사항

- Windows의 QR 표시, LAN/외부 주소 선택, 연결 코드 복사·적용.
- Android의 QR 카메라 스캐너, 연결 코드 붙여넣기, `soundmanager://pair` 링크 열기와 연결 주소 확인.
- 선택적 Cloudflare Quick Tunnel과 HTTPS/WSS 외부 연결. 라우터 포트포워딩 없이 접속하며 끄기/앱 종료 시 자식 프로세스를 정리합니다.
- 외부 평문 HTTP, 잘못된 QR, 중복 필드, 잘못된 버전·형식 거부. Android의 인증 요청 리다이렉트 차단.
- Windows ZIP/릴리스 서명 Android APK 생성, 체크섬과 GitHub Releases 배포 도구.

## 검증과 제한

.NET 테스트 38개와 Android 연결 정보 테스트 5개를 통과했습니다. 실제 공개 Cloudflare 경로에서 HTTPS 상태/인증/설정 변경 및 WSS 합성 PCM 19,200 bytes 수신과 렌더를 검증했습니다. Android 카메라 스캔, 모바일 통신사 경로, 실제 Bluetooth 청취·지연 검증은 별도 필요합니다.

외부 모드는 시험용 임시 터널로 가용성을 보장하지 않으며 주소가 재시작 시 바뀝니다. Cloudflare가 트래픽을 중계하고 HTTPS를 종료합니다. 연결 QR/코드는 서버 제어 권한을 포함하므로 연결할 기기에만 공유하세요. HRTF 공간음향, 자동 재연결, 기기별 권한은 후속 범위입니다.
