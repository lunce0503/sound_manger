# Sound Manager v0.3.2

Windows 로그인 시 백그라운드 실행과 서버 자동 시작 설정을 추가했습니다.

1. 기존 앱을 **완전 종료**한 뒤 `SoundManager-0.3.2-windows-x64.exe`를 실행합니다.
2. 사용할 Bluetooth 출력 장치를 선택합니다.
3. **시작 설정 → Windows 로그인 시 백그라운드 실행 및 서버 자동 시작**을 켭니다.

다음 로그인부터 창을 띄우지 않고 트레이에서 서버를 시작합니다. 선택한 출력 장치를 저장하고, 장치 연결·오디오 서비스가 준비될 때까지 5초마다 재시도합니다. 다른 출력 장치로 자동 전환하지 않습니다. 서버 인증 키도 기존 저장소에서 재사용합니다.

자동 실행 옵션은 기본적으로 꺼져 있으며 현재 사용자에게만 적용합니다. 설정을 해제하면 자동 실행 등록과 대기 중인 자동 시작을 취소합니다. 실행 중인 서버는 유지합니다. 완전 종료는 다음 로그인의 자동 실행 설정을 지우지 않습니다. EXE 재실행과 트레이 메뉴로 기존 창을 열 수 있으며 중복된 로그인 실행은 창을 표시하지 않습니다.

로그인 이후 실행되며, PC 절전 중이나 로그아웃 상태에서는 작동하지 않습니다. 외부 네트워크 연결은 앱에서 켜고 새 임시 주소 QR로 연결합니다. 새 버전을 열면 자동 실행 등록도 새 버전으로 갱신합니다.

Windows는 단일 EXE로 배포합니다. Android는 버전을 맞추고 기존 릴리스 서명을 유지했습니다. 자동 실행 등록/해제/업데이트 경로, 저장된 출력 장치 복원, 장치 지연·일시적 실패 재시도, 취소, 숨겨진 창에서 실제 서버 접근을 회귀 테스트로 검증합니다. 실제 PC 재부팅과 Bluetooth 장치의 부팅 후 연결 검증은 별도입니다.
