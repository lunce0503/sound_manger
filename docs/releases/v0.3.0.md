# Sound Manager v0.3.0

Android UI와 인증 유지를 개선하고 Windows 배포를 단일 EXE로 변경했습니다.

- **Windows**: `SoundManager-0.3.0-windows-x64.exe`를 실행합니다. 구성 파일을 사용자 앱 폴더에 자동으로 풀고 앱을 엽니다. 별도 ZIP 압축 해제나 .NET 설치가 필요하지 않습니다.
- **Android**: `SoundManager-0.3.0-android.apk`를 설치합니다. v0.2.0 릴리스와 같은 서명을 사용하므로 기존 릴리스 앱 위에 업데이트할 수 있습니다.

## UI 변경

- 기본 화면을 전체 음량, EQ 진입, 연결된 기기, 휴대폰 소리 전송으로 정리했습니다.
- 주소와 연결 키는 연결 관리/인증 안에서만 보입니다.
- 각 기기의 음소거를 스피커 아이콘 + ‘음소거’ 글자 + 토글 스위치로 표시합니다.
- 360° 방향 조작을 목록에서 별도 창으로 분리해 스크롤과 겹치지 않습니다. 표시된 점만 드래그에 반응하며 취소된 제스처는 설정을 변경하지 않습니다.
- 이퀄라이저는 별도 창에서 조절하고 적용합니다. ‘총합 음원’ 대신 ‘전체 음량’을 사용합니다.

## 인증 유지

QR 인증 성공 후 Android Keystore로 암호화한 연결 정보를 저장합니다. 앱을 다시 열면 자동 연결하고, 네트워크가 일시적으로 끊겨도 인증을 보존해 재시도합니다. 연결 관리에서 저장된 연결을 지울 수 있습니다.

Windows 서버 키도 DPAPI로 암호화해 재시작 시 유지합니다. v0.2.0은 인증을 저장하지 않았으므로 업데이트 후 처음 한 번은 QR 연결이 필요합니다. 재생 오디오 캡처를 위한 Android 시스템 승인은 별도입니다.

Cloudflare 임시 터널을 다시 열거나 LAN IP가 바뀌면 주소가 달라져 새 주소 QR이 필요합니다. 휴대폰 앱만 닫았다 다시 여는 경우에는 기존 인증으로 자동 연결됩니다.

## 검증

.NET 믹서/서버/QR/암호화 저장 테스트와 Android UI·터치·저장·자동 연결 회귀 테스트, Release 빌드·lint 및 APK 서명을 확인합니다. 실제 휴대폰·Bluetooth 음질 검증은 별도입니다.
