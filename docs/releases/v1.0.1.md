# Sound Manager v1.0.1

장시간 사용 중 서버 연결이 끊겼을 때의 복구 동작을 개선했습니다. [이슈 #1](https://github.com/lunce0503/sound_manger/issues/1)

- Windows 서버는 Bluetooth 출력 장치가 일시적으로 끊겨도 음원 연결과 제어를 유지합니다. 선택한 장치를 5초 간격으로 다시 열며, 복구할 때 대기 중의 오래된 오디오를 재생하지 않습니다.
- Windows와 Android에서 음원 전송 중 네트워크가 끊어지면 기존 인증과 기기 ID로 자동 재접속합니다. Android에서는 캡처 권한이 유지되는 동안 새 캡처 승인이 필요하지 않습니다.
- 서버는 일시적인 음원 수신 시간 초과를 재접속 가능한 종료로 처리합니다. Windows의 진단 화면에 수신 시간 초과와 전송 오류 횟수가 표시되고, 로컬 로그에는 출력 복구 시도와 WASAPI 오류 코드가 남습니다.

Windows는 단일 EXE로 배포하며 Android는 기존 키로 서명했습니다. 기존 앱의 업데이트 메뉴에서 설치할 수 있습니다.
