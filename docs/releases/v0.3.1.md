# Sound Manager v0.3.1

Windows 창을 닫아도 서버와 오디오가 백그라운드에서 계속 동작하도록 변경했습니다.

- `SoundManager-0.3.1-windows-x64.exe`를 실행하고 서버를 시작하세요. 기존 버전 앱은 먼저 종료합니다. ZIP 압축 해제나 별도 .NET 설치가 필요하지 않습니다.
- **X / Alt+F4**는 창을 시스템 트레이로 숨깁니다. 믹싱·Bluetooth 출력·음원 전송과 이미 켜둔 외부 HTTPS 터널을 유지합니다. 창을 닫는 것만으로 외부 주소가 바뀌지 않습니다.
- 트레이 아이콘 두 번 클릭, **Sound Manager 열기**, EXE 재실행으로 기존 창을 복원합니다. 같은 사용자·Windows 로그인 세션에서 서버가 중복 실행되지 않습니다.
- 트레이 메뉴 또는 창 하단의 **완전 종료 (서버 중지)**가 실제 종료입니다. 진행 중인 연결 준비를 취소하고 전송·서버·외부 터널을 정리합니다.
- PC 절전 중에는 작동하지 않으며, 로그아웃·PC 종료 후 자동 시작하는 Windows 서비스는 포함하지 않습니다.
- Android는 기능 변경 없이 버전을 맞췄습니다. APK는 이전 릴리스와 같은 서명을 사용하며 저장된 연결을 유지합니다.

WPF 창을 실제로 닫고 복원하면서 HTTP 제어·WebSocket PCM 수신·믹싱이 유지되는지 검사합니다. 중복 실행 신호, 종료 중 중복 요청, Windows 세션 종료도 회귀 테스트에 포함합니다. 실제 Bluetooth 기기에서 장시간 청취 검증은 별도입니다.
