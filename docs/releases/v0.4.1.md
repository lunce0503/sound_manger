# Sound Manager v0.4.1

Windows와 Android에 앱 내부 업데이트를 추가했습니다. Windows 다운로드는 단일 EXE이며 Android는 기존 릴리스 서명을 유지합니다.

- Windows는 새 버전을 자동 확인하고 음원 연결이 없을 때 다운로드합니다. 창이 닫혀 있고 음원·외부 터널을 사용하지 않으면 자동 재시작해 적용합니다. **앱 업데이트**에서 자동 적용을 끄거나 수동으로 확인·적용할 수 있습니다.
- 업데이트 후 서버 역할, 출력 장치, 전체 음량·EQ, 기기별 이름·음량·방향·음소거 및 저장된 인증을 복원합니다. 새 앱의 시작 확인이 실패하면 이전 앱으로 복구하고 해당 버전의 자동 재시도를 보류합니다.
- Android는 자동 확인과 Wi-Fi 자동 다운로드를 지원합니다. **앱 업데이트 → 다운로드한 업데이트 설치**에서 Android 설치 화면을 확인합니다. 처음에는 이 앱의 설치 권한을 허용하고 설치 버튼을 다시 누르세요. 소리 전송 중에는 중지 확인 후 설치하며, 설치 후 캡처 승인은 다시 필요합니다.
- 공식 저장소의 HTTPS 다운로드, RSA 서명, SHA256·크기 및 Android APK의 패키지·버전·기존 인증서를 검증합니다. 릴리스에는 서명된 `update.json`과 `update.json.sig`를 함께 제공합니다.
- Windows가 설치된 Chrome·Edge 확장 폴더를 갱신하고, 확장은 전송이 없는 때 파일 갱신을 자동 반영합니다. 인증과 저장된 탭 ID를 유지합니다.

## 이번 버전 설치

v0.4.0 이하에는 업데이트 기능이 없으므로 **이번에는 EXE와 APK를 한 번 직접 받아 설치해야 합니다.** 앱을 삭제하거나 데이터를 초기화하지 마세요. Windows는 기존 앱을 완전 종료한 뒤 새 EXE를 실행합니다. 기존 브라우저 확장은 확장 관리에서 한 번 새로고침하고 개발자 모드를 유지하세요. 이후 버전부터 자동 갱신 기능을 사용합니다.

외부 Cloudflare 임시 터널을 켠 동안 Windows 자동 적용을 미룹니다. 수동 업데이트로 서버를 재시작하면 외부 주소가 바뀌므로 새 QR 연결이 필요합니다.

## 검증

.NET 62개, Windows 19개, Android 27개, 브라우저 단위 테스트 7개 통과. 실제 Chrome for Testing의 두 탭 PCM 전송, 전송 중 확장 갱신 보류, 대기 중 갱신 및 브라우저 재시작 후 저장된 인증·탭 설정 유지를 확인했습니다. Windows 복구는 격리된 실제 자식 프로세스의 정상 시작·강제 실패·응답 없음으로 검증했습니다. 실제 Android 기기의 설치 승인과 Bluetooth 청취, 실제 사용 중 앱 전체의 버전 간 교체는 별도 점검 대상입니다.
